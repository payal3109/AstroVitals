# AstroVitals — Team ROVEX

Personalized health-monitoring prototype for long-duration space missions.

## What it does
- Generates a clearly **simulated** dataset for 5 astronaut profiles over 180 days.
- Uses each astronaut's first 30 days as an individual baseline, then a rolling 30-day personal norm so slow mission drift is not flagged.
- Combines direction-aware robust Z-score checks (median/MAD) with an Isolation Forest model.
- Displays explainable anomaly alerts and suggested next steps.
- Saves mood check-ins locally in SQLite.
- Runs locally without requiring a cloud account or external API.

## Important data and science note
All daily heart rate, sleep, activity, mood, stress, radiation-index, bone-index and muscle-index records generated by `simulate.py` are synthetic demonstration data. The injected events are artificial test cases. They are not actual astronaut medical records, personal radiation dosimetry, or validated clinical thresholds.

NASA OSDR OSD-343 and NASA Twins Study are research references for background context; this prototype does not claim that the generated daily records came from those studies or that its numerical thresholds were clinically calibrated from them. NOAA SWPC is a space-weather context resource; the demo radiation index is simulated and is not a measured astronaut dose.

## Tech stack
Python, Flask, Pandas, NumPy, scikit-learn, SQLite, HTML, CSS.

## Setup
Python 3.10+ recommended.

```bash
# 1. Create and activate a virtual environment
python -m venv .venv

# Windows PowerShell:
.venv\Scripts\Activate.ps1

# macOS/Linux:
source .venv/bin/activate

# 2. Install packages
pip install -r requirements.txt

# 3. Generate the demo data
python simulate.py

# 4. Start the app
python app.py
```

Open http://127.0.0.1:5000

Optional: set `SECRET_KEY` for the session secret and `FLASK_DEBUG=1` to enable debug mode (off by default).

## Test data
Synthetic anomalies are injected on:
- AST-002: days 67 and 68 (heart rate, sleep, stress)
- AST-004: day 112 (activity and mood)
- AST-001: day 145 (radiation index)

The application uses these cases to demonstrate anomaly detection. Detection is not guaranteed to identify every injected case because the model and thresholds are illustrative.

## Limitations and safety
This is a hackathon research prototype, not a medical device. It does not diagnose, predict clinical events, or replace astronaut/flight surgeon judgement. Thresholds and synthetic indices are not medically validated. Any real mission deployment would require validated sensors, clinical review, privacy/security controls, verification and operational approval.
